# Portofoliu Proiecte CAD - SolidWorks

Acest repository contine fisierele si documentatia pentru proiectele de modelare asistata de calculator, realizate in SolidWorks. Lucrarile acopera o progresie de la modelarea geometrica de baza pana la piese cu geometrii complexe si tehnici avansate de editare.

## Descrierea Fisierelor

### Intro_Interfata_Modelare_Baza
Acest document introduce interfata aplicatiei si modurile de vizualizare a spatiului de lucru. Sunt detaliati pasii pentru crearea corpurilor geometrice fundamentale, precum paralelipipedul si conul, utilizand functii esentiale de extrudare si revolutie a schitelor.

### Modelare_Dupa_Desen_Mirror
Fisierul descrie procesul de transformare a unui desen tehnic 2D intr-un model 3D, punand accent pe respectarea stricta a cotelor si constrangerilor. Sunt prezentate tehnici de eficientizare a timpului de lucru, inclusiv utilizarea simetriei (Mirror Entities) si aplicarea tesiturilor sau racordarilor direct in etapa de schitare.

### Offset_Convert_Trim_Piesa_Ghidare
Proiectul se concentreaza pe modelarea unei piese de ghidare de complexitate medie, care necesita decupaje precise si lamelaje. Sunt introduse comenzi utile pentru preluarea geometriei existente, precum Offset Entities si Convert Entities, alaturi de functia Trim pentru ajustarea contururilor.

### Geometrie_Complexa_3DSketch_Loft
Documentul abordeaza modelarea avansata a pieselor cu forme atipice, utilizand schite tridimensionale pentru definirea planelor auxiliare de referinta. Include tehnici de taiere dupa plane inclinate (Surface Cut), realizarea decupajelor variabile intre profiluri diferite (Cut Loft) si gravarea textului 3D pe suprafete.

### Piesa_Complex
Piesele necesita combinarea creativa a tehnicilor de modelare studiate anterior pentru a rezolva geometrii variate si pentru a interpreta corect desenele de executie.
